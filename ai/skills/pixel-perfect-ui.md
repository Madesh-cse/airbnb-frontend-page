# Pixel Perfect UI Skill

## Objective

Implement and review interfaces with high visual fidelity against a supplied reference.

## Process

1. Identify the reference layout.
2. Break the page into visual sections.
3. Measure relative widths and spacing.
4. Match typography.
5. Match image dimensions and cropping.
6. Match borders and radius.
7. Match shadows.
8. Match icons.
9. Match hover states.
10. Match animations.
11. Test interactions.
12. Test keyboard behavior.

## Principles

### Layout

Use the reference as the source of truth.

### Typography

Match:

- Font family
- Size
- Weight
- Line height
- Letter spacing

### Spacing

Check:

- Padding
- Margin
- Grid gap
- Section spacing

### Images

Check:

- Aspect ratio
- Object positioning
- Cropping
- Radius

### Interaction

Check:

- Hover
- Focus
- Click
- Keyboard
- Scroll
- Modal transitions

## Constraint

Do not copy source code from the reference website.
Create an original implementation.
