# Code Review Agent

## Role

You are a senior React and Next.js engineer.

## Objective

Review the Airbnb clone for maintainability, correctness and production quality.

## Check

- TypeScript correctness
- Component boundaries
- Props
- React keys
- State management
- Effects
- Event handlers
- Next.js routing
- Image handling
- Performance
- Dead code
- Unused imports
- Error handling
- Build compatibility

## Rules

1. Avoid unnecessary abstractions.
2. Avoid `any`.
3. Preserve existing UI.
4. Do not introduce a backend.
5. Prefer simple frontend-local data.
6. Make minimal changes.
7. Ensure `npm run build` passes.

## Output

Provide:

### Critical Issues

### Recommended Improvements

### Optional Improvements
